# 来源格式与业务语义

支持来源限定 SEG-Y rev1/rev2 基本文件：3200 文本头、400 二进制头、声明数量的扩展文本头、240 道头与样本。默认样本数/间隔位于二进制头第 21/17 字节，道覆盖位于第 115/117 字节，坐标 scalar 位于第 71 字节。支持 sample format 1 IBM、2 int32、3 int16、5 IEEE32、8 int8；本地样例为 IEEE32。负 scalar 表示除其绝对值，零表示 1。未知扩展头数量应按协议标记判断或阻塞，不猜首道位置。

本地演练夹具由 `sampledata.py` 生成，均为虚构业务数据。`sample` 是当前可查看输入，`invalid` 是边界失败输入，其余用于对照来源变体。生成不会下载资源。

本地 HTTP 演练器采用方法与原始路径作为路由键，值为按调用次数返回的响应数组，耗尽后维持最后一项。响应可定义 status、headers、text/base64、require_headers、chunk_bytes、disconnect_after。每次请求保留方法、路径、头与正文摘要表示，便于核对实际访问；演练器只监听回环地址。

原始输入上限 16 MiB 是现有查看入口的保护值，不代表未来持续采集需一次读完整来源。格式含义和截断错误不能被 HTTP 200 覆盖。

## 道索引、坐标解释与抽取约定（traces.py）

解释配置含 byte_order（必须显式 big/little，缺失或非法报 uncertain_byte_order，不嗅探）、extended_headers（declared 或非负整数，覆盖卷头未声明的情形）、max_samples（道长上界）。索引以（文件指纹 SHA-256，解释配置指纹）为主键存于 SQLite；文件被替换后指纹变化，旧偏移不再使用。扫描、指纹与抽取均为流式读写，不把整文件装进内存。

索引可恢复：扫描按批提交并记录游标，中断后下次从游标续扫；失败运行在相同输入下重建。解析失败即停并记录原因：未知样本格式、道头样本数为零或超过 max_samples、道数据越过文件末尾、扩展文本头数量未声明，均不通过寻找下一段看似合理的数值来跳过。

坐标解释：scalar 正值相乘、负值除以其绝对值、零取因子 1（不得把坐标清零）；单位按道头第 89 字节代码解释（1 长度、2 角秒、3 十进制度、4 度分秒），未知代码标记 units_known=false，一律不默认经纬度。样本数与采样间隔：定长标记置位时以卷头默认为准，否则道头第 115 字节覆盖；道头间隔为 0 时回落卷头默认，输出均标注来源（trace/binary）。

抽取按测线号（道头第 9-12 字节野外记录号）与测线内道序号段返回原始字节（道头与样本原样拼接），附 SHA-256、range_complete 与 delivery_verified 标记；抽取与预览前后复核文件指纹。预览中 delivery.verified 仅在完整扫描到文件末尾且无错误时为 true；截断等未验证交付的已索引道仍列出并标记 readable，两者明确区分。
